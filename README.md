**الحالة الحالية، 6 أكتوبر 2026:** تعمل المحطات الخمس، ونجح التكامل الفعلي مع Gemini Flash-Lite المجاني للتفاعل الاختياري. يحتاج الموقع متغيرات Vercel الموضحة أدناه. أُدخل ملف الاختبارات المراجع: 106 حالات مقبولة، ونجحت 47/47 حالة dev للمدقّق بعد تحميل الترجمات البديلة الموجودة أصلًا بإسنادها الصحيح. هذه نتيجة تطوير محدودة وليست دقة عامة. الفهرس الدلالي الكامل غير منجز بسبب حصة Google، ونسخة العرض تعمل دونه. بدأ كتابة التطبيق في 4 أكتوبر 2026، وتواريخ المصادر محفوظة كما وردت.

## Gemini المجاني — إعداد 6 أكتوبر

أكد صاحب المشروع أن مفتاحه تابع لمشروع **Free tier دون ربط بالفوترة** وطلب عدم إجراء طلبات مدفوعة. يحل هذا الطلب محل ميزانية التطوير السابقة. اشتراك Google AI Pro للتطبيق منفصل عن حصة API.

متغيرات الخادم المطلوبة محليًا وفي Vercel:

```dotenv
GEMINI_API_KEY=مفتاح_مشروع_Free_غير_مرتبط_بالفوترة
GEMINI_MODEL=gemini-3.1-flash-lite
GEMINI_FREE_TIER_CONFIRMED=true
GEMINI_RUNTIME_ENABLED=true
```

المتغير `GEMINI_FREE_TIER_CONFIRMED` يسجل تأكيد المالك ولا يستعلم عن الفوترة. ضمان عدم التحصيل يأتي من بقاء مشروع Google على Free tier بلا فوترة. لا تربطه بحساب دفع. عند 429 يتوقف الطلب دون تبديل مفتاح أو نموذج، وتبقى وظائف المصادر متاحة. تعاد محاولة JSON غير الصالح مرة واحدة؛ أخطاء المزود في التوليد لا تعاد. بعد ضبط متغيرات Vercel، نفّذ Redeploy لآخر إصدار. لا ترسل المفتاح في المحادثة أو Git.

```powershell
npm run env:check
npm run gemini:check
```

الأول لا يتصل بـGoogle. الثاني يجري فحصًا صغيرًا حقيقيًا للتكامل المجاني. الخيار `-- --retrieval` يضيف أربع حالات بحث عامة باللغات الأربع؛ هذا فحص تشغيل وليس تقييم دقة معتمدًا. قد تستخدم Google مدخلات الحصة المجانية لتحسين منتجاتها؛ يوافق الزائر على البيانات المرسلة قبل استعمال المزايا الاختيارية.

## النشر على Vercel

1. بعد رفع المشروع إلى مستودع GitHub، افتح Vercel واختر Add New → Project.
2. اربط حساب GitHub واختر المستودع `mohammadsajjadbd2026/sanad`.
3. اختر Next.js، واجعل Root Directory جذر المستودع (`./`).
4. اترك Build Command على `npm run build` وOutput Directory على إعداد Next.js الافتراضي.
5. انشر الواجهة الأولى دون مفاتيح. قبل تفعيل Gemini أضف GEMINI_API_KEY وGEMINI_MODEL وGEMINI_EMBED_MODEL في Settings → Environment Variables ثم أعد النشر.
6. لا تستخدم NEXT_PUBLIC_ لمفاتيح Gemini ولا تضع المفتاح في المحادثة أو Git. محليًا استخدم `.env.local` اعتمادًا على `.env.example`.
7. النسخة الحية الحالية: https://sanad-lovat-gamma.vercel.app/ . اتبع إعداد Gemini المجاني أعلى الملف؛ إعداد المفتاح وحده لا يفعّل التفاعل.

ملفات المصادر وdata تبقى ملفات خادم ولا توضع في public. لا تشمل النسخة الأولى صفحة لاستعراض نصوص بيّنات.

## المرحلة الثانية: المصادر والبحث الدلالي

أضيفت محمّلات محمية بوحدة `server-only` للقرآن وترجماته والأحاديث وبيّنات، مع التحقق من البنية بواسطة Zod والتوقف عند مصدر ناقص أو غير صالح. نصوص العرض تعود كما هي من المصدر. نسختا التطبيع للبحث والمقارنة منفصلتان؛ تطابق البحث وحده لا يثبت صحة اللفظ أو الحكم.

أضيف SDK الرسمي `@google/genai` لإنشاء البصمات، و`@next/env` لتحميل إعدادات الخادم، و`server-only` لمنع استيراد وحدات المصادر والخدمات في مكونات العميل.

### ضبط الخدمة محليًا

ضع المفتاح في `.env.local` (مستبعد من Git)، واختر نموذجًا متاحًا لحسابك:

```dotenv
GEMINI_API_KEY=ضع_مفتاحك_محليًا
GEMINI_EMBED_MODEL=gemini-embedding-2
GEMINI_EMBED_DIMENSIONS=768
```

`GEMINI_MODEL` مخصص للنموذج التوليدي في المرحلة التالية. لا يحتاجه بناء البصمات. أمر `npm run env:check` يطبع وجود الإعدادات فقط دون قيم المفتاح.

### أوامر الفهرسة بالترتيب

```powershell
npm run embeddings:plan
npm run embeddings:sample
npm run embeddings:build
```

الأول لا يتصل بـ API. الثاني يفهرس عينة من 20 مرجعًا موزعة على أنواع المصادر. الثالث يكمل جميع المصادر ويعيد استخدام عناصر العينة المحفوظة. الفهرسة ترسل النصوص المرجعية اللازمة إلى Google عبر المفتاح، وقد تحتسب تكلفتها بحسب خطة الحساب. لا ترسل بيانات المراجعين أو ملفات الاختبار أو ملفات Excel/PDF كاملة.

الفهرس يحتوي مستندًا واحدًا لكل مرجع: 6236 آية مع ترجمات معانيها، و54 حديثًا مع صيغه المترجمة، و25 سؤالًا من بيّنات. الأجوبة تسترجع من المصدر لاحقًا. يرسل Embedding 2 نصًا واحدًا لكل طلب لأن إرسال قائمة قد يدمج مراجع مختلفة في بصمة واحدة. مهمة البحث مضمنة في صيغة الإدخال وفق توثيق Google. الصيغ الأصلية لا تتغير.

البصمات في `data/embeddings/` ملفات مشتقة، وليست نصوصًا أو أحكامًا جديدة. تحفظ في أجزاء من 100 عنصر مع بصمة للمصدر واسم النموذج والأبعاد. يُرفض استعمال فهرس قديم بعد تغيير المصادر أو النموذج. لا يفعّل `active.json` إلا بعد اكتمال التشغيل الكامل، وتُحفظ كل استجابة ناجحة قبل الطلب التالي. إعادة التشغيل تستأنف الناقص فقط. القفل `build.lock` يمنع التشغيل المتزامن، وقد يلزم إزالته يدويًا بعد التأكد من توقف عملية انقطعت قسرًا.

طلبات الخدمة متتابعة بفاصل ثانية افتراضيًا لتخفيف ضغط الحصة. يمكن تغيير حجم دفعة المعالجة والفاصل بأمر مثل `npm run embeddings:build -- --batch-size 5 --delay-ms 10000`. تعاد الأخطاء المؤقتة 3 مرات كحد أقصى؛ أخطاء المفاتيح والصلاحيات لا تعاد. لا تخفض الفاصل إلا ضمن حصة حسابك.

تقارير `results/embeddings-sample.json` و`results/embeddings-full.json` تنشأ عند نجاح التشغيل الفعلي فقط. العدد المحفوظ بدقة 1261/6315؛ توقف الاستئناف عند HTTP 429 من Google. الفهرس غير مفعّل، ووظائف نسخة العرض تعمل دونه. لا تكرر الطلبات قبل تجدد الحصة. نجاح الفهرسة ليس تقييمًا لدقة المدقّق.

## وظائف نسخة العرض الحالية

- `/draft`: مطابقة محافظة للنصوص المسجلة، حكم الحديث بلفظه من المصدر، تقرير قابل للطباعة إلى PDF، ملفات TXT/DOCX تُقرأ في المتصفح. ضع الاقتباس في سطر مستقل أو بين علامتي اقتباس لتتحسن المطابقة. عدم العثور لا يعني الوضع.
- `/produce` و`/publish`: بحث لفظي في النصوص، بطاقة من نص مصدر ثابت موثوق، قالبان PNG، نسخ ومشاركة WhatsApp أو نظام الجهاز، حفظ مرجع البطاقة في المتصفح وإعادة التحقق منه عند التصدير. لا تُصدّر الأحاديث الضعيفة أو المختلف عليها. تظهر إرشادات القاموس المطابقة للنص العربي أو الإنجليزي للمراجعة فقط؛ لا تغيّر النص. يوجد خيار وصف قصير موسوم «مولّد» بعد اختيار الجمهور وموافقة مستقلة، لكنه مغلق على الموقع الحي حاليًا. لا تُستخدم ملفات الجمهور المتعارضة a-02 وa-03.
- `/practice`: بحث لفظي عربي، وبحث اختياري عبر Gemini بالعربية والإنجليزية والبنغالية والأردية. تُرسل عناوين الأسئلة وسؤال البحث بعد موافقة صريحة، ويقبل النظام معرّفات موجودة فقط. يختار القارئ السؤال المرشح لعرض جوابه العربي حرفيًا مع الصفحة. لا يولّد الميدان جوابًا دينيًا أو ترجمة.
- `/prepare`: سؤال من بيّنات وإجابة المستخدم ثم المرجع وتقرير الاقتباسات. يراعي التقييم الاختياري اسم الجمهور والنبرة المختارين صراحة، دون استنتاج سمات عن المستخدم أو استعمال خلفية الجمهور غير المراجعة.
- يتطلب تفعيل Gemini المتغيرات الأربعة المبينة أعلى الملف. يوافق المستخدم على الإرسال؛ تتحقق الخدمة من JSON ثم تعيد محاولة واحدة عند خرج غير صالح. أخطاء المزود أو نفاد الحصة توقف الطلب. لا يصدر عن النموذج آية أو حديث أو حكم أو مرجع أو حالة تحقق.
